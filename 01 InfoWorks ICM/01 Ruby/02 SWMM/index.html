What the robustness pass adds

  • # frozen_string_literal: true pragma at the top of every fix_ file.
  • Header docblock — purpose, inputs, outputs, UI vs Exchange, hardening notes.
  • begin / rescue => e / ensure around main logic so transactions roll back, files close, and the error trail surfaces cleanly.
  • Pre-flight validation — current_network not nil, selection non-empty, prompts not cancelled, file paths exist.
  • File I/O via block forms File.open(...) do |f| ... end and CSV.open(...) do |csv| ... end.
  • Timestamped progress logging [HH:MM:SS] ... so batches show liveness.
  • Nil-safety with &. and explicit next if ro.nil? guards.
  • Per-row rescue so a single bad row doesn't abort the batch.
  • transaction_begin / transaction_commit paired with transaction_cancel on rescue, only when the original used transactions.
  • For very large Exchange importers, fix_ uses a thin delegating wrapper via Kernel#load to add the outer safety net without touching the original logic.
